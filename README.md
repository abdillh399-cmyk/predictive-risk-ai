# تنبؤ المخاطر الذكي - Predictive Risk AI

نظام متقدم لتقييم وتنبؤ المخاطر باستخدام الذكاء الاصطناعي.

## المميزات الرئيسية

- 🧠 تقييم ذكي للمخاطر باستخدام AI
- 📊 مصفوفة مخاطر تفاعلية
- ✅ التحقق من معايير السلامة الدولية
- 📈 إنشاء وتحليل التقارير
- 🎯 لوحة تحكم احترافية

## التثبيت والتشغيل

```bash
pnpm install
pnpm dev
```

## البنية

- `client/` - واجهة المستخدم (React + Tailwind)
- `server/` - خادم Express
